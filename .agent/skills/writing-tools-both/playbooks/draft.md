# Draft

New prose from a brief, notes, or facts.

1. Run Layer 1, Plan. Done when the branch tags, mission, plan, and evidence notes exist.
2. Write the whole draft from beginning to end before any editing.
3. Run Layer 2, Structure, on the draft.
4. Run Layer 3, Passage.
5. Run Layer 4, Sentence.
6. Recheck every rule touched by a later layer's fixes. Done when every applied rule from all layers still passes.
7. Run Layer 5, Deliver, then deliver.
