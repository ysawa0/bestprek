# Revise

Edit, tighten, shorten, or restyle supplied prose.

1. Lock the scope: what the user authorized, and what stays byte-identical. A narrow request, such as spelling only, ends here with that fix delivered.
2. Run Layer 1, Plan, against the existing text. Done when the mission and structure map exist.
3. Run Layer 2, Structure.
4. Run Layer 3, Passage.
5. Run Layer 4, Sentence. Qualifiers move into the middle of the sentence; they stay in the text.
6. Recheck every rule touched by a later layer's fixes. Done when every applied rule from all layers still passes.
7. Run Layer 5, Deliver, then deliver.
