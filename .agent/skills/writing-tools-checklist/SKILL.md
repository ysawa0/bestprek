# Writing Tools

Read all of [rules.md](rules.md) before beginning. Its 55 rules are authoritative. A rule with a Target line applies when its target appears; rules without a Target line apply throughout.

## Ground rules

- Preserve facts, quantities, names, ownership, uncertainty, and proposal status. Added nonfiction claims require evidence; invention belongs to fiction.
- Honor the authorized edit scope. Preserve quotations and out-of-scope text exactly. A spelling-only request gets spelling fixes alone.
- Keep the requested genre. Narrative rules apply within narrative passages.
- Every applicable Pass line is a requirement. Deliver when the applicable rules, requested form, and length are satisfied; disclose irreconcilable conflicts.
- Return the requested prose plus essential gaps or conflicts. Rule results belong in a requested audit; working notes stay private.

## Work

1. Lock the authorized scope. Classify the form and make the mission, outline, and evidence notes. For revision, map the existing structure first; a spelling-only request ends with the authorized fix.
2. Complete the whole draft before editing. Revise its structure, passages, and sentences.
3. Make a private checklist numbered 1–55. For each rule, record PASS with the actual passage or working-note evidence, NO TARGET with the absent object, USER OVERRIDE with the conflicting instruction, or NEEDS REPAIR with the defect. Evaluate every applicable Pass line against the current draft; fluent prose alone is not evidence of a process step.
4. Repair every NEEDS REPAIR entry. Recheck rules affected by each repair, including facts, paragraph boundaries, emphasis, and length. Finish when the checklist accounts for all 55 and every applicable rule passes or has a disclosed conflict.
5. Run the reader self-review and deliver the requested prose. Keep the checklist private unless the user requests an audit. In an audit, report each rule in scope and cite the passage and repair for each failure; an exhaustive audit accounts for all 55.
