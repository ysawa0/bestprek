# Revise

Edit, tighten, shorten, or restyle supplied prose.

1. Lock the scope: what the user authorized, and what stays byte-identical. A narrow request, such as spelling only, ends here with that fix delivered.
2. Record the branch tags and read every selected branch file. Map the existing structure.
3. Revise structure, then paragraphs, then sentences and words, applying every selected rule. Qualifiers move into the middle of the sentence; they stay in the text.
4. Check every applied rule's Pass line. Done when each passes after its fix and a recheck of the rules that fix touched.
5. Deliver.
