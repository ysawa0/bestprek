# Draft

New prose from a brief, notes, or facts.

1. Record the branch tags and read every selected branch file.
2. Lock the brief, mission, plan, and evidence notes the selected rules require.
3. Write the whole draft from beginning to end before any editing.
4. Revise structure, then paragraphs, then sentences and words, applying every selected rule.
5. Check every applied rule's Pass line. Done when each passes after its fix and a recheck of the rules that fix touched.
6. Deliver.
