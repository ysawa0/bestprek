# Draft

New prose from a brief, notes, or facts.

1. Lock the brief: reader, purpose, form, voice, and length. Done when the Rule 40 mission sentence and, for a multi-section piece, the Rule 31 key question exist in working notes.
2. Gather the evidence (Rule 42). Done when every key claim has a source in the supplied material or a recorded gap.
3. Classify the piece as report, story, or hybrid (Rule 25).
4. Plan the opening, each section's job, and the ending (Rules 24 and 39). A short message gets a one-line plan.
5. Write the whole draft from beginning to end before any line editing (Rule 48).
6. Run steps 3–6 of [Revise](revise.md) on the draft.
7. Run the Rule 47 reader check, then deliver.
