# Draft

New prose from a brief, notes, or facts.

1. Lock the brief: reader, purpose, form, voice, and length. Write the Rule 40 mission sentence and the Rule 31 key question in working notes.
2. Gather the evidence (Rule 42). Use supplied facts as given. Record each gap rather than filling it.
3. Classify the piece as report, story, or hybrid (Rule 25).
4. Plan (Rule 24): the opening, the job of each section, and the ending (Rule 39). Use one line for a short message.
5. Draft from beginning to end without line editing (Rule 48).
6. Revise the draft with steps 3–6 of the [Revise](revise.md) playbook.
7. Run the Rule 47 reader check, then deliver the prose with only essential gap notes.
